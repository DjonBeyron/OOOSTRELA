=====================================================================
 КАК ОБНОВИТЬ ПРОГРАММУ НА ЭТОМ ПК
=====================================================================

ОБЫЧНО (каждый раз, когда Claude сказал «запушил»):

  В этой папке дважды щёлкнуть:   update.cmd

  Он сам: остановит старый сервер → скачает новое из GitHub →
  при необходимости поставит пакеты → соберёт сайт → запустит сервер.
  В конце: "Version now: 0.1.X" и "Strela gateway v0.1.X".
  Окно НЕ закрывать — в нём работает сервер.

  Потом в браузере:  http://localhost:8787   (если старая версия — Ctrl+F5)


ТО ЖЕ САМОЕ ВРУЧНУЮ (если update.cmd почему-то не сработал):

  Открыть PowerShell и выполнить по очереди:

    cd C:\ProjectsStrela\OOOSTRELA
    git pull
    .\scripts\start.ps1


ПРОСТО ЗАПУСТИТЬ (без обновления, например после перезагрузки ПК):

  Дважды щёлкнуть:   start.cmd


СКРЫТЫЕ СТРАНИЦЫ (только для владельца):

  http://localhost:8787/#diag    — диагностика, кнопка «Скопировать дебаг» для Claude
  http://localhost:8787/#admin   — админка: вопросы, ответы, рассуждения модели


ЕСЛИ ОШИБКА — скопировать весь текст из чёрного окна и отправить Claude.
