# Strela AI — инструкции для Claude Code

Этот файл подгружается автоматически в каждую сессию в этой папке. Только правила — план в
`PROJECT.md`, карта файлов в `STRUCTURE.md`.

## Язык
Отвечай **всегда на русском**, коротко и по делу.

## Как мы работаем
- Claude работает на удалённом сервере, **не** на ПК с RTX 5090. Код туда попадает через git
  (`git pull` + `scripts/update.ps1`). Пользователь тестирует на реальной машине и присылает
  дебаг-блок из диагностической панели — по нему и ставим диагноз.
- Любая новая функция на стороне ПК сразу получает строку в `/diag` (что включено, версия,
  время, последняя ошибка). Без диагностики фичу не считаем готовой.
- Пушить в git — только по явной просьбе пользователя, каждый раз новая просьба.

## Версия
Константа `APP_VERSION` в `packages/shared/src/version.ts`, формат `0.1.X`. **При любом
изменении кода — +1 к последней цифре.** Показывается мелко в шапке фронта и в `/diag`
gateway — так видно, что до ПК/Vercel дошла свежая сборка.

## Размер файлов (код и CSS)
- Ориентир **250 строк**, твёрдый потолок **400** — `npm run lint` падает (`max-lines`).
- Один файл — одна ответственность. Растёт — дели по смыслу, выноси в подпапку.
- В конце ответа: список изменённых файлов с **итоговым** числом строк (`ChatView.tsx — 180
  строк`), не diff. `version.ts` не включать.

## Структура
- `apps/web/` — React-фронт (Vite). `apps/web/src/features/<имя>/` — одна фича = одна папка
  (`chat/`, `admin/`, `diag/`). `apps/web/src/shared/` — общее для ≥2 фич.
- `apps/web/api/` — Vercel Functions (прокси к gateway, админ-API).
- `apps/gateway/` — сервис на ПК с 5090 (Node + Hono): прокси к Ollama/ComfyUI, `/diag`.
- `packages/shared/` — типы контракта web ↔ api ↔ gateway и версия. **Любое изменение
  формата запроса/ответа — сначала тут**, чтобы вторая сторона сломалась на компиляции, а не
  молча в рантайме.

## Секретность железа и модели
Пользователь в интерфейсе видит **только номер версии**. Имя модели, GPU, VRAM, скорость,
время генерации, тексты ошибок Ollama — никогда не попадают в UI и в ответы API к браузеру
(только в `/api/diag` и скрытую панель `#diag`). Ошибки пользователю — общим текстом.

## Код
- TypeScript strict, без `any` без причины. Компоненты — `PascalCase.tsx`, функции —
  `camelCase.ts`.
- Без лишних абстракций: обёртка появляется, когда нужна минимум двум местам.
- Анимаций в приложении максимум 2–3 на всё приложение, только `transform`/`opacity`.
  Уважаем `prefers-reduced-motion`.
- Цвета/шрифты/отступы — только через CSS-переменные из `apps/web/src/styles/tokens.css`.
- Секреты — только в `.env` (в git не попадают), пример в `.env.example`.
- Gateway по умолчанию слушает `127.0.0.1`; снаружи доступен только через туннель и только с
  заголовком `x-gateway-token`.

## Документы
- `PROJECT.md` — что строим, этапы, принятые решения, открытые вопросы.
- `STRUCTURE.md` — строка на каждый файл. Создал/удалил файл — в том же шаге обнови.
