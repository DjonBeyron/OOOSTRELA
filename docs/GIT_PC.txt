=====================================================================
 STRELA AI — как получать свежий код на ПК с RTX 5090 через git
=====================================================================

Схема: Claude пишет код на своём сервере → push в GitHub → ты на ПК
делаешь update → проверяешь → присылаешь дебаг-блок.

Все команды — в PowerShell (обычном, НЕ от администратора).


---------------------------------------------------------------------
 ОДИН РАЗ: регистрация и репозиторий
---------------------------------------------------------------------
1. Завести аккаунт GitHub (бесплатный):  https://github.com/signup
2. Создать ПУСТОЙ приватный репозиторий:  https://github.com/new
   - Repository name: strela-ai
   - Private
   - НЕ ставить галочки README / .gitignore / license
3. Прислать Claude ссылку на репозиторий (вида
   https://github.com/<логин>/strela-ai).


---------------------------------------------------------------------
 ОДИН РАЗ: скачать проект на ПК
---------------------------------------------------------------------
  cd C:\
  git clone https://github.com/<логин>/strela-ai.git
  cd C:\strela-ai
  .\scripts\start.ps1

При первом clone Git откроет окно входа в GitHub — войти через браузер
(это Git Credential Manager, пароль запомнится).

Первый запуск: npm ci ставит зависимости (~1 минута), потом сборка,
потом строка:
  Strela gateway v0.1.X
    open:   http://localhost:8787

Открыть в браузере на этом ПК:  http://localhost:8787
Окно PowerShell НЕ закрывать — в нём работает сервер. Остановить: Ctrl+C.


---------------------------------------------------------------------
 КАЖДЫЙ РАЗ, когда Claude сказал «запушил, обновляй»
---------------------------------------------------------------------
В окне, где работает сервер: Ctrl+C (остановить). Затем:
  cd C:\strela-ai
  .\scripts\update.ps1

Скрипт сам: git pull → при необходимости npm ci → сборка → запуск.
В конце печатает "Version now: 0.1.X" — сверь с номером, который
назвал Claude. Этот же номер виден мелко в шапке сайта рядом с
"Strela AI".

Если в браузере старая версия — Ctrl+F5 (обновить без кэша).


---------------------------------------------------------------------
 КАК ОТДАВАТЬ ДЕБАГ CLAUDE
---------------------------------------------------------------------
1. На сайте нажать ⚙ (справа вверху) → «Диагностика».
2. «Скопировать дебаг» → вставить в чат Claude целиком.
3. Если сайт вообще не открывается — скопировать ВСЁ из окна PowerShell,
   где запускался start.ps1 / update.ps1.

Сырые данные без сайта:  http://localhost:8787/api/diag


---------------------------------------------------------------------
 ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------------------------------------------------------
- "FAILED: git pull" — на ПК правили файлы проекта. Посмотреть:
    git status
  Правки на ПК не нужны (всё приходит через git). Сбросить их:
    git checkout -- .
  (файл apps\gateway\.env не трогается — он не в git)
- "running scripts is disabled" — не выполнен шаг 6 из SETUP_PC.txt:
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
- "WARNING: Ollama is not responding" — запустить Ollama из меню Пуск
  (иконка ламы должна появиться у часов), потом снова start.ps1.
- Порт 8787 занят другой программой — в apps\gateway\.env поменять
  PORT=8788 и открыть http://localhost:8788
