Проблема переполнения стека памяти

Много бесед

всё держится в памяти

Рабочая память

почти заполнена

Перезагрузка

сейчас — вручную (долгая перезагрузка интеллекта)

Цель: интеллект сам освобождает память, без остановки работы.

У интеллекта есть «рабочий стол» — стек памяти, где лежат текущие разговоры. Когда он переполнен, интеллект начинает работать хуже, и его приходится перезапускать, как зависший компьютер. Сейчас это делается вручную, и перезагрузка занимает много времени. Задача — чтобы он сам наводил порядок, не прерывая работу.
