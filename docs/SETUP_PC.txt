=====================================================================
 STRELA AI — установка на ПК с RTX 5090 (Windows)        этап 0
=====================================================================

Порядок важен: ставь сверху вниз. После каждого шага — проверка.
Все проверки делаются в PowerShell (Пуск → набрать "PowerShell" → Enter).
После установки программы ЗАКРОЙ и заново открой PowerShell, иначе
новая команда не найдётся.


---------------------------------------------------------------------
 ШАГ 1. Драйвер NVIDIA (обязательно свежий — для 5090 нужен CUDA 12.8+)
---------------------------------------------------------------------
Вариант А (проще) — приложение NVIDIA App, само найдёт драйвер:
  https://www.nvidia.com/ru-ru/software/nvidia-app/

Вариант Б — вручную (выбрать GeForce → RTX 50 Series → RTX 5090 →
Windows 11 → тип драйвера: STUDIO):
  https://www.nvidia.com/ru-ru/drivers/

Какой драйвер: STUDIO. Для нейросетей он такой же быстрый, как игровой
(Game Ready), но выходит реже и дольше тестируется — меньше шансов, что
обновление что-то сломает. В NVIDIA App это переключается в разделе
"Драйверы" → три точки → "NVIDIA Studio Driver".
Минимум для 5090 и CUDA 12.8: драйвер версии 570 или новее.
Автообновление драйвера лучше выключить: обновляем вручную, когда всё
работает, а не посреди теста.

После установки — перезагрузить ПК.

ПРОВЕРКА:
  nvidia-smi
Должна появиться таблица с "NVIDIA GeForce RTX 5090",
справа сверху "CUDA Version: 12.8" или выше.


---------------------------------------------------------------------
 ШАГ 2. Git for Windows
---------------------------------------------------------------------
  https://git-scm.com/download/win
Скачать "64-bit Git for Windows Setup". При установке все галочки
оставлять по умолчанию, просто "Next".

ПРОВЕРКА:
  git --version
Ответ вида: git version 2.xx.x.windows.x


---------------------------------------------------------------------
 ШАГ 3. Node.js 22 LTS
---------------------------------------------------------------------
  https://nodejs.org/en/download
Выбрать версию 22 (LTS), Windows, x64, скачать ".msi" установщик.
Галочку "Automatically install the necessary tools" — НЕ ставить.

ПРОВЕРКА:
  node -v
  npm -v
Ответ: v22.x.x и 10.x.x (или выше)


---------------------------------------------------------------------
 ШАГ 4. Ollama (движок, который запускает нейросеть)
---------------------------------------------------------------------
Страница:        https://ollama.com/download/windows
Прямая ссылка:   https://ollama.com/download/OllamaSetup.exe

После установки Ollama сама запускается и висит иконкой-ламой в трее
(возле часов). Она должна быть запущена всегда, когда работаем.

ПРОВЕРКА:
  ollama --version


---------------------------------------------------------------------
 ШАГ 5. Скачать модель (текстовая нейросеть Qwen3-30B-A3B)
---------------------------------------------------------------------
Страница модели: https://ollama.com/library/qwen3

Размер ~19 ГБ, нужно свободное место на диске C: минимум 25 ГБ.
В PowerShell:
  ollama pull qwen3:30b-a3b

Дождаться строки "success".

ПРОВЕРКА — поговорить с моделью прямо в консоли:
  ollama run qwen3:30b-a3b
Написать: Привет! Расскажи в двух предложениях про тайгу.
Выход из чата: /bye

Пока модель отвечает — в другом окне PowerShell:
  nvidia-smi
Должно быть видно, что занято ~18-22 ГБ видеопамяти (процесс ollama).


---------------------------------------------------------------------
 ШАГ 6. Разрешить запуск наших скриптов (.ps1)
---------------------------------------------------------------------
Позже для обновления будут скрипты start.ps1 / update.ps1.
Windows по умолчанию запрещает скрипты. Один раз выполнить:
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
На вопрос ответить: Y


---------------------------------------------------------------------
 ЕСЛИ ЧТО-ТО НЕ ТАК
---------------------------------------------------------------------
- Загрузка с ollama.com / nodejs.org зависает или обрывается —
  попробовать через VPN.
- "команда не найдена" — закрыть и заново открыть PowerShell,
  если не помогло — перезагрузить ПК.
- Модель отвечает очень медленно (слово в секунду и медленнее) —
  значит, не использует видеокарту. Прислать вывод:
    nvidia-smi
    ollama ps

---------------------------------------------------------------------
 БОНУС. Цвета / шрифты / лого с сайта strela27.ru
---------------------------------------------------------------------
1. Открыть https://strela27.ru/ в Chrome.
2. F12 → вкладка Console.
3. Если Chrome не даёт вставить — сначала набрать: allow pasting
4. Вставить строку ниже целиком, Enter. Результат скопируется в буфер
   обмена — прислать его мне.

(()=>{const c={},f={},bg={};document.querySelectorAll('*').forEach(e=>{const s=getComputedStyle(e);c[s.color]=(c[s.color]||0)+1;bg[s.backgroundColor]=(bg[s.backgroundColor]||0)+1;f[s.fontFamily]=(f[s.fontFamily]||0)+1});const top=o=>Object.entries(o).sort((a,b)=>b[1]-a[1]).slice(0,15);const r={text:top(c),bg:top(bg),fonts:top(f),fontLinks:[...document.querySelectorAll('link[href*="font"],link[rel=stylesheet]')].map(l=>l.href),logos:[...document.querySelectorAll('img,svg')].filter(i=>/logo/i.test(i.outerHTML.slice(0,300))).map(i=>i.src||i.outerHTML.slice(0,2000)),icon:[...document.querySelectorAll('link[rel*=icon]')].map(l=>l.href),h1:getComputedStyle(document.querySelector('h1')||document.body).fontFamily};copy(JSON.stringify(r,null,1));return r})()

Если лого не нашлось — прислать файл логотипа (svg или png).
